# 표류자 — 캐릭터·소품·로케이션 생성 가이드

이 문서는 레퍼런스 이미지를 만들고 고르는 기준이다. 실제 생성 요청은 `refs.json`에 정의돼 있다. 실행은 `tools/grok_chain.py ep01 refs`로 한다. 비율과 색의 기준은 `model_sheet.svg`(미리보기 `model_sheet_preview.jpg`)를 따른다.

## 1. 디자인 결정과 이유

| 결정 | 이유 |
|---|---|
| 무광 자기 질감의 **달걀형 얼굴 없는 머리**(회백 #D8D5CF) | '문명'의 검은 동그란 머리와 겹치지 않게 했다. 표정이 없어 AI 영상에서 얼굴이 무너지는 실패 모드가 원천적으로 없다. 시청자가 별명을 붙이게 만드는 빈칸 역할도 한다. |
| 머리 = 전체 키의 약 1/4 (바이블 1:2.2 → 1:3으로 조정) | 2.2등신이면 장난감·유아 캐릭터로 읽혀 '아동용' 재분류 위험이 있다. 손작업 샷(대나무 자르기·마개 깎기)에는 팔 길이도 필요하다. |
| 주황 구명조끼 + 주황 고양이 | 검은 현무암 해안 위 9:16 작은 화면에서 0.5초 안에 식별된다. 썸네일 식별색도 이 둘이다. |
| 맨발, 바지 걷음 | EP.4 「짚신」이 필요한 이유를 EP.1부터 보여 준다(연속성). |
| 고양이 식별점 3개(왼귀 홈·흰 가슴·흰 앞발 2개) + 목걸이 | 주황 태비는 흔하다. 3개 특징으로 매 샷 동일 개체인지 검수한다. 목걸이 원판은 EP.5 떡밥이라 EP.1부터 달고 있어야 한다. |
| 실제 고양이 행동만, 의인화·위기 연출 금지 | 정책의 'animals in exaggerated distress' 리스크를 피한다. 아동 소구도 줄인다. |

## 2. 생성 순서 (약 1시간, 이미지 약 40장 × $0.04 ≈ $1.6)

0. **(권장) 손 스케치 10분.** `model_sheet_preview.jpg`를 보고 종이에 주인공 정면을 대충 그린다. 사진을 찍어 `characters/sketch/P_sketch.jpg`로 저장한다.
   - 스케치가 있으면 `P` 작업이 스케치를 입력으로 쓴다(`prompt_from_sketch`).
   - 사람 창작 기여의 증거가 된다(가드레일 B-11).
1. 베이스 3종을 먼저 만든다.
   ```
   python3 tools/grok_chain.py ep01 refs --only P --live
   python3 tools/grok_chain.py ep01 refs --only C --live
   python3 tools/grok_chain.py ep01 refs --only L01 --live
   ```
   각 4장 후보가 `characters/refs/_candidates/`에 생긴다.
2. 아래 3절 기준으로 1장씩 고른다. 예: `pick-ref P 3`. 기준을 통과한 후보가 없으면 같은 명령을 다시 실행한다(후보는 덮어쓴다).
3. 파생 레퍼런스를 만든다. 확정한 이미지를 편집해서 만들므로 정체성이 유지된다.
   - `refs --only P_side`, `P_back`, `P_kneel`, `C_walk`, `C_crouch`를 각각 실행하고 고른다.
4. 소품을 만든다.
   - `refs --only PLANK`, `refs --only BAMBOO`를 실행하고 고른다.
   - 그다음 `refs --only FLASK`를 실행한다. 대나무와 널빤지 확정 이미지를 합쳐서 편집하므로 이 순서를 지킨다.
5. `sheet`를 실행해 `characters/refs/P_sheet.png`, `C_sheet.png`를 만든다. 사람이 4각도를 한눈에 보며 최종 확인한다.

영상 요청에 실제로 들어가는 레퍼런스는 `P`, `C`, `BAMBOO`, `PLANK`, `FLASK`와 S01 키프레임용 `L01`이다. 측면·후면·자세 파생본은 검수용이다. 드리프트가 심한 샷에서만 shots.json의 refs에 추가한다(영상 레퍼런스 한도 14장, 편집 입력 한도 5장).

## 3. 레퍼런스 고르는 기준 (하나라도 실패하면 탈락)

**주인공 P**
- [ ] 머리에 눈·코·입·귀·주름·음영 얼굴이 **전혀** 없다(빛 반사로 생긴 얼굴형 음영도 탈락).
- [ ] 달걀형이고 위가 약간 넓다. 머리가 전체 키의 1/5~1/3 범위다.
- [ ] 손가락이 5개이고 손이 머리와 같은 재질이다(장갑 아님).
- [ ] 조끼가 주황이고 검은 버클이 3개다. 호루라기가 왼쪽 어깨끈(인물 기준 왼쪽 = 정면에서 화면 오른쪽)에 있다.
- [ ] 맨발이고 바지를 종아리까지 걷었다. 로고·글자가 없다.
- [ ] 장난감·마네킹 관절처럼 보이지 않는다. 성인 체형의 자연스러운 서 있는 자세다.

**고양이 C**
- [ ] 왼쪽 귀(고양이 기준 왼쪽 = 정면에서 화면 오른쪽) 끝에 V자 홈이 있다.
- [ ] 흰 가슴이 있고 흰 앞발이 2개, 뒷발은 주황이다.
- [ ] 가는 가죽 끈 목걸이에 놋쇠 원판이 1개 있고 글자가 보이지 않는다.
- [ ] 마른 성체다. 새끼 고양이 비율(큰 머리·큰 눈)이 아니다.

**소품·로케이션**
- [ ] PLANK: 쇠못이 1개이고 사각 대가리, 녹이 슬어 있다. 각인 글자가 보이지 않는다(EP.2 떡밥 F1 전).
- [ ] BAMBOO: 지름이 약 6cm(손으로 감싸 쥘 수 있음)이고 마디 간격이 30cm 안팎이다.
- [ ] FLASK: 바닥이 마디로 막혀 있다. 마개는 어두운 참나무다. 높이 대 지름 비가 약 5:1이다.
- [ ] L01: 사람·건물·배·콘크리트·전선·플라스틱이 없다. 화면 아래 중앙에 널빤지 1장, 가운데 1/3은 비어 있다.

## 4. 영상 안에서 정체성을 지키는 장치

1. **레퍼런스 동봉.** 모든 영상 요청에 그 샷에 나오는 인물·소품 레퍼런스를 함께 넣는다(`reference_images`). 시작 프레임은 `<IMAGE_0>`, 레퍼런스는 `<IMAGE_1>`부터다.
2. **정체성 문장.** 실행기가 영상 프롬프트 끝에 "Keep the figure exactly as in `<IMAGE_n>`; its head stays a smooth, featureless matte porcelain egg in every frame."를 자동으로 붙인다.
3. **재고정.** C(이어가기)는 최대 3연속이고, 실제 장면표에서는 1연속뿐이다. 나머지는 A·T 링크로 처리한다. A·T 링크에서는 앞 끝 프레임과 레퍼런스를 함께 넣고 이미지 편집으로 새 시작 프레임을 만들기 때문에, 그때마다 정체성이 레퍼런스 기준으로 다시 맞춰진다.
4. **탈락 규칙.** 클립 어느 한 프레임이라도 머리에 얼굴 요소가 생기면 그 클립은 쓰지 않는다. 아웃 포인트 앞이라도 쓰지 않는다.
   - 같은 샷이 2회 연속 탈락하면 프롬프트에서 머리 쪽을 가리는 동작(고개 숙임·뒤돌기)을 늘린다.
   - 또는 `last_frame`에 시작 프레임 편집본을 고정해 끝을 묶는다.

## 5. 앱(grok.com)에서 수동으로 만들 때

레퍼런스를 여러 장 올릴 수 없는 경우를 위한 방법이다.
- **레퍼런스·시작 프레임 만들기:** 이미지 편집 창에 `refs.json`의 `prompt`를 그대로 붙여 넣는다.
- **영상 만들기:** 시작 프레임 1장을 올리고 `ep01/shotlist.md`의 "레퍼런스 없이 앱에 시작 프레임 1장만 올릴 때" 프롬프트를 쓴다. 이 프롬프트에는 정체성 설명이 문장으로 들어 있다.
- **끝 프레임 추출:** `ffmpeg -sseof -0.05 -i 클립.mp4 -frames:v 1 끝.png`로 뽑는다. 다만 실제로 쓸 아웃 포인트가 클립 끝이 아니면 `ffmpeg -ss <아웃초> -i 클립.mp4 -frames:v 1 끝.png`로 그 지점의 프레임을 뽑는다.
