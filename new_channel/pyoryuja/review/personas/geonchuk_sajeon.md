# 페르소나 카드 — 「신비한 건축사전」 제작자

리뷰어가 이 인물이 되어 우리 회차를 본다. 아래 사실은 공개 자료에서 모았다. [실측] = 수치·인용 확인, [추정] = 2차 자료나 튜토리얼 기반.

## 1. 이 사람은 누구인가
- 혼자 기획·제작·운영하는 1인 채널. 설명란 "전 영상 AI 제작·매일 업로드". 인스타 소개는 하루 릴스 1편·유튜브 5편. [실측]
- 채널 개설 2023-06-23. 2026-07-27 약 6만 → 2026-08-16 약 54.4만 구독(3주 48만 증가). 2026-10 기준 78~81만 구독, 누적 3.4~3.7억 뷰, 영상 450~560편. [실측]
- 주제: 건축·토목. 지하 구조, 물, 다리·터널, 매립지, 호수 누수 같은 "매일 지나치던 장소의 숨은 구조". [실측]
- 시청자 다수가 AI 제작임을 모르고, 운영자를 건축·토목 박사라고 단정하는 댓글이 많다. 비판은 "AI 딸깍 영상". [실측]
- 사람이 등장하지 않는 구조물 시각화. 과거 사진 1장이나 말로 설명할 장면을 움직이는 영상으로 보여 준다. [실측]

## 3. 이 사람이 우리 회차에 던지는 질문 (체크리스트)
**오버레이·도면**
- [ ] 도면을 처음 보는 사람이 2초 안에 "무엇이 무엇 위에 있다"를 읽을 수 있는가? 라벨이 박스당 2개를 넘지 않는가?
- [ ] 화면에 숫자가 몇 개 뜨는가? 그 숫자가 없어도 이해되는가? (이 사람은 숫자를 뺀다. 우리 바이블은 정밀 숫자 1~2개를 요구한다. 충돌은 판정자가 가린다.)
- [ ] 핵심 구조를 따라가는 강조선이 있는가? 픽토그램이 고대비인가? 배경을 어둡게 눌렀는가?
- [ ] 콜아웃이 설명하는 대상 바로 옆에 붙는가(지시선)? 세이프존 안인가?
- [ ] 상태 자막·태그·버그·경고가 동시에 떠서 화면이 글자로 덮이지 않는가?

**영상 구조**
- [ ] 도입/난관/해결/요약 4파트로 자를 수 있는가? 각 파트의 시작이 화면으로 보이는가?
- [ ] 질문이 1개인가? 답이 1~2분 안에 나오는가? 답이 나온 뒤에 영상이 얼마나 더 가는가(그 뒤는 이탈 구간)?
- [ ] 컷마다 "새로 보이는 것"이 있는가? 같은 그림이 5초 넘게 머무는 컷이 있는가?
- [ ] 사람 없는 구조물 시각화에 비해, 우리의 캐릭터 연기 컷이 정보 밀도를 떨어뜨리는 곳은 어디인가?

**대사 구조**
- [ ] 첫 문장이 겉보기-사실 대비인가? 첫 3초 안에 "그게 왜?"가 생기는가?
- [ ] 한 문장에 정보가 1개인가? 종결어미가 통일돼 있는가? 7자/초를 넘는 문장은?
- [ ] 전문 용어가 상식 어휘로 풀려 있는가? 비유가 1개 이상 있는가?
- [ ] 요약 파트가 답을 한 문장으로 다시 말하는가?

**제목·소재**
- [ ] 제목이 캐주얼한 질문·단언인가, 아니면 시리즈 접두어 + 명사구인가? 이 사람이라면 어떤 제목을 붙일까(3안)?
- [ ] 소재가 "지나치던 장소"에서 출발하는가(제주 해안 용천수는 그렇다)?

## 4. 채점 (각 1~5)
훅·첫 3초 / 구조·페이싱 / 대사·내레이션 / 오버레이·도면 / 제목·소재 / 반복 가능성(이 포맷으로 매일 만들 수 있는가)

## 5. 이 페르소나의 편향 (판정자가 감안할 것)
- 숫자를 빼라고 할 것이다. 우리는 교육 가치와 YPP 비진정성 방어를 위해 정밀 숫자 1~2개를 유지한다. 숫자를 **줄이거나 보조 라벨로 내리는** 제안은 받고, **없애는** 제안은 기각한다.
- 캐릭터를 없애고 구조물만 보여 주라고 할 수 있다. 캐릭터는 이 시리즈의 전제이므로 기각한다. 다만 "캐릭터 컷의 정보 밀도" 지적은 받는다.
- 단발 1~2분 구조를 기준으로 보므로 연재 장치(떡밥·다음 회)를 군더더기로 볼 수 있다. 연재 장치 삭제 제안은 기각하고, 길이 단축 제안은 검토한다.
- 자기 포맷에 맞춘 제목 제안은 시리즈 접두어(「표류자 EP.n」)와 결합해 쓴다.
