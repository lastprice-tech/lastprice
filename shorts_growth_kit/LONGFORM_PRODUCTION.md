## (b) 썸네일·제목 규칙 카드

### 썸네일 제작 규칙 (skia 템플릿)
- **주 이미지: 실사(PD/CC0 > CC BY > CC BY-SA) 또는 코드 도면만.** 실존 유적을 사진처럼 그린 AI 이미지는 썸네일 금지. 근거: AI 썸네일 CTR 효과는 독립 검증 근거 없음 / 플레이어 라벨("변경되거나 합성된 콘텐츠")과 썸네일의 "진짜 사진" 인상이 불일치 / 교육 니치 AI 반감(Fern "Death of Educational Content" 1,090만 뷰) / Kurzgesagt 오탐 사례. AI를 쓴다면 청사진·라인아트 등 명백히 비사실적 룩만.
- **원형 3종 고정** (니치 리더 — Animagraffs, Practical Engineering, Primal Space, Real Engineering, History Matters — 최근 썸네일 75개 분석, 조회수 기반 관찰 [측정-약]):
  - **T1 X-ray reveal**: 실사 일부를 벗겨 도면 단면, 텍스트 0
  - **T2 Defect callout**: 서클·하중 화살표 1개 + 1~3단어
  - **T3 Then·Now / Intact·Ruin 분할**
  - 인물 실루엣 1개는 규모감용 옵션. 얼굴 불필요.
- 텍스트 0~3단어, ≤18자, 제목과 겹치는 명사 금지. 지시어("WHY DID THIS CRACK?")를 쓰면 화살표·서클이 결손 부위를 반드시 가리킴.
- 팔레트 2색 고정(도면 시안 + 경고 오렌지), 굵은 산세리프 1종, 배경 탈채도, 로고 없음.
- `[자동]` 세이프존(우하단 22%×16% 재생시간, 하단 6% 진행바, 우상단 12%×18%) 침범 0, 텍스트 높이 ≥캔버스 9%, 대비 ≥4.5:1, 주 피사체 ≥50%, 그레이스케일 분리 통과. `[수동]` 168×94 축소본 3초 판독.
- **약속-이행**: 영상 첫 프레임(0~3초) = 썸네일 주 이미지와 같은 사진·구도(perceptual hash 검사). 썸네일의 결손 콜아웃은 20초 안 Q1 답 장면에서 같은 그래픽으로 재등장(manifest에 `thumb_match_t` 기록). 공식 리텐션 가이드의 **Intro(30초 잔존)**가 이 일치를 측정한다.
- 이미지 URL·작가·라이선스를 메타데이터에 저장 → 설명란 크레딧 자동 생성. 원본 가로 ≥2,000px.

### 제목 규칙
- 템플릿: **[유적 고유명] + [긴장 술어]**. 예: "Why didn't this bridge fall?" → "Why the Pont du Gard Never Fell".
- 질문형·길이·괄호 효과는 대규모 데이터에서 ≈0 [측정]. 차이를 만드는 것은 엔티티 구체성과 긴장.
- 쇼츠 질문 원문은 0~10초 내레이션·썸네일 지시어에 쓰고, 제목은 엔티티형으로 재작성. 10만+ 쇼츠 2편의 원문 질문은 A/B 제목 변형 1안으로 넣어 원문형 vs 엔티티형을 직접 비교.
- "추천이 LLM으로 제목을 읽는다"는 공식 발언은 미확인. 다만 2025 Google 발표(Large Recommender Models)상 제목·설명·자막·오디오·프레임으로 semantic ID를 만들어 신규 영상 콜드스타트에 쓴다 → 제목 엔티티가 내레이션·설명란·챕터에 일관되게 들어가는지 자동 검증(위 엔티티 일관성).

### A/B 테스트 프로토콜 [공식 조건 확인]
- 조건: 최대 3안(제목만/썸네일만/조합), ≤2주, 승자 = 시청시간, Inconclusive → 첫 업로드 안이 기본, 테스트 중 수정 시 자동 중단, 쇼츠·프리미어·비공개 제외, Advanced features·데스크톱 필요. 'Stop & Set' 수동 종료 옵션 있음.
- 14일 예상 노출 <5,000이면 **2안만**. 두 안은 원형(T1 vs T2/T3)이 다른 것. 색·문구만 바꾼 변형 금지.
- 가장 자신 있는 안을 '첫 번째'로 등록. 3안은 노출 1만 이상 영상에서만.
- 필요 표본(α=0.05, 검정력 0.8, 직접 계산): CTR 8%→10.4% 검출에 안당 ≈2,300 노출. **노출 2,000 미만 결과는 '학습 불가'로 기록.** Inconclusive를 '첫 안 우세'의 증거로 쓰지 않음.
- 결과는 원형 라벨 + 시청시간 점유율로 시트에 기록. Winner 3회 또는 롱폼 5편 전에는 채널 기본 원형 확정 금지.
- 다이내믹 썸네일·Ask Studio 자동 썸네일 리프레시는 첫 10편 D0~D28 동안 끔(결과 미공개로 학습 오염).

### 수동 교체 프로토콜
- 업로드 후 72시간 판단 금지 [공식 "Avoid checking your CTR immediately after uploading"].
- CTR 판정은 Analytics > Reach > 트래픽 소스별 노출·CTR 표로. Browse+Suggested 노출이 50% 미만이면 '판정 보류'. Browse 노출 500 이상 쌓인 뒤에만 판정.
- 교체 조건 3개 동시 충족: 누적 노출 ≥1,000 **AND** Browse CTR이 채널 Browse 기준선의 70% 미만 **AND** Intro 30초 잔존이 채널 평균 이상(= 클릭이 문제).
- 썸네일 먼저, 한 번에 1개, 간격 7일 또는 신규 노출 1,000 중 늦은 쪽, 영상당 최대 2회, 전후 소스별 CTR·AVD 로그.
- CTR 정상인데 Intro 평균 미만 → 썸네일을 '덜 과장'. CTR 정상인데 노출 정체 → 패키징 문제 아님, 교체 금지(주제·리텐션 점검). 재업로드 금지.

### 4. 진단 트리 (가장 앞에서 실패한 게이트 하나만 고침)
| 게이트 | 판정 | 실패 시 레버 |
|---|---|---|
| **G0 데이터 충분성** | 조회 <100 또는 노출 <1,000 → '결론 보류', 기본값 불변 | — |
| **G1 노출** | D28 노출 <1,000 → 분배 미개시 = 주제·수요 문제 | 다음 편 주제: 부모 쇼츠 상위 25% + Stayed to watch·구독/1천뷰 중앙값 이상 |
| **G2 소스별 CTR** | Browse CTR이 공식 범위 2~10% 안이고 채널 중앙값 −2%p 이내면 통과 | 썸네일·제목(A/B 또는 교체 프로토콜) |
| **G3 Intro 30초** | 잠정 하한 50%, 목표 60%(외부 경험치 [참고]; 3편 후 자체 중앙값으로 교체) | 0~20초 구성(영상 컷 A/B 출시 전까지는 쇼츠 테스트베드) |
| **G4 챕터별 조건부 낙차** | D_c = 1−R(e_c)/R(s_c), d_c = D_c/((e_c−s_c)/60), B_c = R(s_{c+1}+6s)/R(e_c−6s). d_c > 챕터 2~5 중앙값×1.5 플래그, B_c<0.95가 2편 연속이면 고리 문장 형식 변경 | 챕터 길이·비주얼 밀도 |

| **G6 구독/1천뷰** | — | 엔드스크린·연결 |

### 5. 변수 1개 실험 — 검증 경로
- **경로 A 영상 내부 교차설계(가장 강력, 영상 간 잡음 없음)**: 챕터 2 = AI 클립 12초당 1개, 챕터 4 = 20초당 1개, 다음 편 맞바꿈. 지표 = 세그먼트 시작 후 2포인트 안 `stoppedWatching` / 해당 시점 시청자('시작점 이탈률'). 10편 합산 유형별 이탈률 비와 95% CI. **AI 클립 비 ≥1.2이고 CI 하한이 1을 넘으면 AI 상한을 40% 아래로.** 처음 2포인트·마지막 5% 제외. 편당 조회 ≥500 전에는 관찰만. (6분 영상 = 포인트당 3.6초, 5초 클립 ≈1.4포인트, 10편이면 클립 시작점 ~250개가 표본.)
- **경로 B YouTube 네이티브 A/B**: 썸네일·제목(현재), 0~20초 3컷(영상 컷 A/B — 2026-09-23 Made on YouTube 발표, 'coming soon'). 파이프라인에 오프닝 20초만 바꾼 변형 렌더 기능 추가.
- **경로 C 쇼츠 테스트베드**: 훅 문장 후보는 쇼츠 3편(첫 2초만 다르게)으로 Stayed to watch 비교 후 롱폼 0~10초에 채택.
- **경로 D 영상 간 ABAB**: 변수 1개만. 우선순위 0~20초 구성 > 챕터 길이 > 5분 vs 7분(편당 1,000뷰 이후).
- 필요 표본(α=0.05, 검정력 0.8, 그룹당, 직접 계산): CTR 6→9% ≈1,200노출, 6→8% ≈2,550, 30초 잔존 50→60% ≈390명, 50→65% ≈170명, APV 30→38% ≈550명. 영상당 100~300뷰면 Intro 10%p 차이 확인에 그룹당 2~4편 → **10편으로 영상 간 변수는 1~2개가 한계**.
- 판정 규칙: 짝지은 4쌍 중 3쌍 이상 같은 방향 AND 합산 차이가 최소효과 초과일 때만 기본값 변경. 그 외 '차이 없음' → 비용 싼 쪽 고정. CTR 3%p 미만·30초 잔존 10%p 미만 차이는 잡음.
