0. 직답 — 벤치마크만으로는 왜 안 되는가

한계 1. 벤치마크는 결과(포맷 문법)만 주고 메커니즘(몇 초에서 왜 붙잡는가)을 주지 않는다. 남의 리텐션 커브는 볼 수 없다 — 원리적으로 복제 불가능한 정보다.

한계 2. 벤치마크 채널의 업로드 목록은 "이미 공급된 주제"의 목록이다. 따라가면 수요-공급 공백을 정의상 놓친다.

전환. 그래서 벤치마크를 버리는 게 아니라 용도를 바꾼다: 문법 교본 → 수요 센서(아웃라이어 마이닝 대상). 형식 복제 자체는 천장이 아니다 — Zack D. Films 문법을 역사 도메인으로 옮겨 4년 1,455편을 쏟은 His Story는 600만 구독을 만들었다. 천장은 형식·도메인·속도가 전부 겹칠 때 온다. 강

벤치마크를 넘어서는 우위의 서열 (기대 효과 × 복제 불가능성)

  1. 아이템 발굴 삼각측량아이디어가 조회수 상한을 정한다. 수요×인지도×공백 교집합은 벤치마크 업로드 목록에 없다. §2
  2. 자기 채널 계측 루프슬롯 단위 리텐션 귀속 + 훅 유형 태깅. 벤치마크가 물리적으로 줄 수 없는 유일한 데이터이며, 변형 재렌더 ~$1인 이 파이프라인에서만 복리로 쌓인다. §6
  3. 훅 엔지니어링단기 효과 최대 — 단, 2번의 자기 데이터 없이는 캘리브레이션이 안 되는 종속 활동. §1
  4. 복제 비용 높은 시각 자산장식이 아닌 진짜 도면 문법(단면·하중 경로·해칭). 카피캣 포화 시점의 방어벽. §4
  5. 패키징·유통각각 한 자릿수 % 이득. 자동화라 비용 0이니 전부 하되 기대는 낮게. §5

1. 훅 설계 — 감이 아니라 공식

확신 50% 법칙 강

궁금함은 시청자의 정답 확신이 약 50%일 때 최대(fMRI, 역U자). 훅 = 친숙한 물건 + 통념이 틀렸다는 신호.Everyone thinks earthquakes did this. The stone says otherwise.

구체성도 역U자 강

Upworthy 8,977건 A/B 재분석: 훅 실패 다수가 "너무 구체적이라 격차가 닫힌" 경우. 숫자·고유명사는 1–2개만, 원인(메커니즘)은 은폐. SOLUTION 키워드가 훅·제목에 있으면 반려.

부정 어휘의 인과 효과 강

10.5만 헤드라인 RCT(Nature Human Behaviour): 부정 단어가 클릭을 인과적으로 올림. 가점 렉시콘 {missing, killed, banned, collapsed, shouldn't…} / 감점 {amazing, incredible}.

병적 호기심 = 인간 행위 강

"인간이 만든 위험"만 중립보다 선호됨(자연재해·순수 사고는 아님). 같은 붕괴도 알고도 방치·도둑질·금지된 공법 각도를 선택.

운영 규칙

  • 아이데이션 순서 역전: 주제→대본이 아니라 훅 5개 생성 → 최강 훅 선택 → 에피소드 각도 역산. 훅-SOLUTION 정합성 셀프체크(훅의 명사가 SOLUTION에 문자 그대로 재등장, 불일치 반려). 중
  • 발화 제약: 첫 문장 ≤8단어(2.5초 내 격차 개방), 12단어 내 페이오프. TTS 렌더 후 첫 문장 >2.6초면 재생성. 5초 지점까지 SOLUTION의 존재를 예고하는 반문장 의무.
  • 첫 프레임 = 썸네일: 결정 창 ~2초. 프레임 0에 훅 텍스트(≤5단어)와 오브젝트(화면 40%+)가 t=0부터 존재, 도면 선은 0.3–0.5초부터 그려지기 시작(완성 팝업·페이드인 금지). 프레임 0 PNG 단독 심사 게이트.
  • 도메인 앵커: 12단어 안에 구조물명·연도·공학 명사 ≥1 — LLM 기반 추천이 텍스트로 클러스터를 정하므로 무도메인 미스터리 훅은 오배포됨.

3. 대본 — 12슬롯 v2

진단: 이탈 위험 3곳 — EASY PART(긴장을 푸는 교과서 구간), SUMMARY(반복 = 문서화된 이탈 원인), CLOSING(완결감이 루프를 죽임). 2025-03-31부터 리플레이 1회 = 조회수 1회이므로 루프는 지표에 직결된다. 강

#슬롯 (65초 기준)규칙
1HERE IS 0–4s≤12단어 내 페이오프, 정밀 숫자·날짜 1개, SOLUTION 키워드 금지
2NOT BECAUSE 4–9s오해 부정 = 열린 루프 #1
3OR ELSE 9–14s위험을 2인칭으로 — you 투입 1/2
4TRAP (구 EASY PART) 14–20s쉬운 부분을 함정으로 프레이밍. 끝문장 ≤6단어 + X 동기화
5PROBLEM 1 20–27s재훅 #1: 의문문/반전 접속 + 미등장 명사 1개
6WHAT IF→NO 27–33s런타임 45–55% 지점, 에피소드 최대 시각 이벤트(풀 X)
7PROBLEM 2 33–40s재훅 #2: 문제 1보다 스테이크가 커야 함
8STAKES (구 SUMMARY) 40–44s요약 금지. 3항 압축 ≤12단어 Three failures. One winter. Zero room for error.
9PIVOT 44–48s재훅 #3
10SOLUTION 48–57s최저 속도(0.95x), 정밀 숫자+치수선 1:1, you 금지
11EFFECT + SEED 57–63s방어 가능한 최상급 단정 1개(반례 댓글 유발), you 투입 2/2
12CLOSING LOOP 63–68s"That is the ___" 발화 종료 즉시 컷(트레일링 무음 ≤0.3s, 아웃트로·CTA 금지) + 마지막 프레임 = 첫 프레임 구도
  • 워드버짓 축소: 120–190 → 145–170단어(≈135–155 WPM). 190단어/60초는 명백한 과속. 중
  • 정밀 숫자 2–4개, 반올림 금지 — "측정해본 사람"이라는 신뢰 신호. 각 숫자 ↔ 오버레이 라벨 1:1 매핑 린트.
  • TTS 구조 변경: break 태그 남용은 ElevenLabs 공식 아티팩트 경고 → 슬롯별 개별 생성 + ffmpeg concat에서 무음 갭(0.3–0.8s) 코드 삽입. 오버레이와 프레임 동기화, KR/JP 길이 차는 갭 조정으로 흡수. 강
  • 리듬 린트: 연속 3문장 ±3단어 균일 시 경고, 각 슬롯 끝 ≤6단어 펀치 문장(오버레이 비트와 동기).
  • 불가침 축(변주 금지): 데드팬 2인칭, 시그니처, 오브젝트 주인공, 에코 원칙. 변주 축(4–6주 주기): 훅 문형, 전환 스타일, 오버레이 리듬 — "벤치마크 천장"은 이 표면층에서만 온다.

4. 영상 — 컷은 그대로, 컷 안을 채운다

  • 12컷×5초 유지: 60초당 ~12샷이 몰입 역U의 실측 정점(Reels 1,200편 계산모델)과 이미 일치 중 — 대신 각 5초 클립 안에 오버레이 이벤트 ≥2개(2.0–2.5초 간격): 치수선 드로잉·라벨·존·X. 화면 정지 2.5초 초과 = QC 실패.
  • 완성 상태 즉시 표시 금지: 만족감의 기제는 예측→확인 도파민 루프 + 자이가르닉 효과. 오버레이는 그어지고·채워지고·조립되는 과정일 때만 가치가 있다. 치수선 0.7–1.2초 드로잉, X 두 획 순차, 재조립은 스냅+오버슈트. 강
  • 리빌 예산: 최대 리빌(분해도→재조립)은 SOLUTION에만. HERE IS는 봉인된 외형(내부 노출 금지), TRAP에 첫 단면, WHAT IF에 고스트 X-ray, EFFECT에 전/후. 분해도가 SOLUTION 이전에 나오면 린트 반려.
  • 진행 장치: 타임바 대신 하단 미니 블루프린트 누적기 — 슬롯마다 도면이 채워지되 시작 시 외곽선은 기채움(빈 진행 바는 이탈을 늘림, 32연구 메타분석). PROBLEM 슬롯만 1/2 카운터 허용.
  • AI 이질감 방어: 언캐니 처벌은 실사에 가까울수록 크다 → "시네마틱 일러스트·기술 도해 룩"으로 장르 재정의(코드 도면 오버레이가 그 장치, 커버리지 70%+). 후처리 고정: 그레이드 LUT → 미세 블러 → 그레인 8–15%(에피소드 동일 시드).
  • 사운드(비평가가 잡은 공백): 오버레이 이벤트와 1:1 SFX — 치수선=펜 스크래치, X=스탬프, 재조립=스냅. Zack D. Films의 실제 차별 요소 중 하나가 SFX 밀도다. BGM은 자작/라이선스 프리, −14 LUFS + 덕킹.

6. 실험 시스템 — 벤치마크를 넘는 실제 수단

  • 제작 시점 메타데이터는 그 순간에만 기록 가능하다. SQLite 2테이블: episodes(훅 유형·소재 카테고리·12슬롯 타임스탬프·루프 설계·프롬프트 버전) + snapshots(48h/7d/28d별 views·engagedViews·리텐션 100pt·슬롯 낙차).
  • 슬롯 단위 리텐션 귀속: Analytics API 리텐션 커브는 영상당 100포인트 = 65초에서 0.65초 해상도, 슬롯당 7–8포인트. 강 커브 자동 분류: 3초 절벽형=훅 책임 / 특정 슬롯 낙차 2배=그 슬롯 압축 / 70% 고원+1초 스파이크=성공 패턴 태깅(단, 중반 스파이크는 "되감기 혼란" 가설 먼저 — 오버레이 싱크 점검).
  • 지표는 조회수가 아니라 비율: 2025-03-31부터 조회수는 재생 시작마다 집계되는 허영 지표. 핵심은 stay_rate = engagedViews/views(스와이프 프록시 — 루프 성공작일수록 낮아 보이는 왜곡이 있어 루프 지표와 함께 읽는다), APV, 슬롯 낙차. Studio의 Viewed-vs-Swiped는 API로 못 뽑으므로 주 1회 수동 대조만.
  • 표본 규율: 판정은 engagedViews ≥500 이후, 비율 지표로만. 10%p 차 감지에 변형당 ~350뷰, 5%p 차 ~1,100+. 훅 "유형" 결론은 유형당 ≥8편. 에피소드 1쌍의 조회수 비교는 순차 배포의 운 분산 때문에 n=1이다. 에피소드 비교는 반드시 같은 나이끼리(48h-vs-48h).
  • 훅 A/B는 본채널 재업로드 금지(반복 콘텐츠 정책 리스크) → TikTok 선행 테스트(24h 순위만, 절대값 비교 금지) 또는 IG Trial Reels(비팔로워 노출 공식 실험 표면).
  • 4주 캘린더: W1 계측(베이스라인) → W2 훅 축(오프너 3종 로테이션) → W3 구조 축(루프 on/off + 최다 이탈 슬롯 압축) → W4 소재 축(아웃라이어 큐 3 + 탐색 2). 불변 룰: 에피소드당 실험 변수 1개 — 고정 12슬롯 포맷이 곧 교란 통제 장치다.

7. 놓치기 쉬운 것 (적대적 비평이 추가한 영역)

콜드스타트 생존

신생 채널 48h 50–500뷰는 정상. 첫 20편은 비율 지표로만 판정(성급한 포맷 폐기 방지), 주제 이탈 금지(시드 학습기), 채널명·설명·키워드도 클러스터 신호로. 초기엔 관련 커뮤니티 사람 손 시딩 주 1–2회.

사실 오류 프로토콜

역사 채널의 자산은 신뢰. 수치·연도 출처 필드 의무화(저장 스키마로), 정정 절차(고정댓글+설명란) 사전 정의, AI 합성 공개 라벨 판정을 업로드 자동화에 포함.

팬덤 장치

업로드 후 첫 60분 댓글 운영(자동 초안+휴먼 승인). 좋은 질문은 다음 에피소드로 회수해 "당신의 질문으로 만들었다" 명시 — 발굴 파이프라인과 커뮤니티를 잇는 루프.

이 문서 자체가 부패한다. YouTube 공식 변경 로그를 주간 크론으로 수집해 하드코딩 임계값과 대조하는 "룰셋 유통기한" 리포트. 자기 지표 급변은 "내 실력"보다 "플랫폼 변경" 가설 먼저.
