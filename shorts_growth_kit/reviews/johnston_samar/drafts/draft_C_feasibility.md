# The Carriers Ran. One Destroyer Turned Around. / 오프닝 카드: "WHY TURN TOWARD THE GUNS?"

관점 C(제작 실현성) · 68.7초 · 23컷 · EN 내레이션 192단어 · 새 Veo 4건. 0–3.4초에는 카드 없이 방향 화살표와 이름표만 둔다. 오프닝 카드는 3.6초에 질문 대사와 같은 문장으로 뜬다. 결말 문장은 처음에 공개하지 않는다.

## 설계 논리

1. 중심 질문은 "항모들이 달아날 때, 왜 한 구축함만 전함 쪽으로 돌았나?"이다. 답은 '시간'이다. 이 답을 마지막 해석 문장 하나에 맡기지 않고 중간 답 네 개로 쌓는다.
2. 공개 순서: 항모는 느리다(12초) → 연막만으로는 못 막는다(15초) → 어뢰는 가까이서만 통한다(26초) → 구마노가 낙오하고 항모는 시간을 번다(34초) → 대가를 치른 뒤 다시 들어가 포화를 끌어오려다 실패한다(50초) → 4척 손실과 목적(69초). 마지막 장면은 첫 장면으로 루프한다.
3. 실현성의 핵심: 새 Veo 4건은 모두 '배나 항공기 전체의 동작 1개'(선회, 함교 시점 접근, 재선회, 급강하)만 요구한다. 발사·명중·포격은 전부 그래픽과 사마르 당일 실제 사진이 맡는다. 발사 박자(원래 C12)는 방식 ①, 기존 어뢰 PNG를 쓴 부채꼴 궤적 그래픽으로 처리한다.
4. 반복 구도 해소: 존스턴 전신이 보이는 선미 사선 컷은 9개에서 0개로 줄인다. 황금 역광 원본 4개는 수평선을 잘라 낸 부분 크롭(갑판·연막·함교·함미)으로만 쓴다. 화면 문법 6가지(수면 저각, 적 전방, 장비 세부, 함교 시점, 도식, 기록 사진)를 돌려 쓰고, 이웃한 두 컷이 같은 문법을 쓰지 않게 한다.
5. 새 생성 4건마다 기존 소스 대체안을 미리 정해 둔다. 어느 하나가 실패하거나 차단돼도 재요청 없이 같은 길이로 완성된다.

## 컷 표

**공통 처리 (모든 컷에 적용)**

- **G-SAMAR 그레이드**: 실사진과 아카이브를 뺀 전 컷에 적용한다. 화이트밸런스는 냉색, 주황 계열 채도 −70%, 하이라이트 채도 −50%, 대비 −10%, 약한 헤이즈. 목표는 스콜이 지나는 흐린 아침이다. 태양은 화면 밖, 미군 등 뒤에 있다고 본다.
- **H-CROP (황금 역광 원본 재사용 조건)**: V_C04·V_C07·V_C14·V_C18_V2에만 적용한다. 9:16 창은 기본 810×1440(1.33배), 상한 1.4배다. 창의 위쪽 끝을 수평선보다 40px 이상 아래에 둔다. 그러면 태양, 하늘, 일본 함대 실루엣이 한 프레임도 화면에 들어오지 않는다. 검수 중 수평선이 보이면 창을 내리고, 그래도 보이면 대체안으로 바꾼다. 대체안: C03은 C04 사진을 5.4초로 늘린다. C05는 80-G-288885로 바꾸고, 이 경우 C13은 T5 평면도의 '항모 이탈' 상태로 바꾼다.
- **스콜 레이어**: 빗줄기와 안개를 담은 2D 레이어(불투명도 10–15%)를 C03·C05·C14·C15에만 얹는다. 피격 뒤 스콜 속으로 피신한 사실과도 맞는다.
- **기록 사진 규칙**: 흑백 원본 톤을 유지한다. 자동 컬러화와 AI 얼굴 보정은 금지한다. "REAL PHOTO · OCT 25, 1944" 표기는 사마르 당일 사진에만 붙인다.
- **원본 속도 1.0**: 리타임은 금지한다(물결이 끊길 위험이 있다). 같은 원본을 여러 컷으로 나눌 때 프레임 구간이 겹치지 않게 한다.
- **화면 영역**: EN 번인 자막은 화면 높이 62–70%에 둔다. 하단 20%와 우측 12%는 쇼츠 UI 자리라 비운다. 카드는 상단 12–20%에 둔다.
- **오버레이 템플릿**
  - T1 방향 화살표: 흰 ←(항모) / 빨간 →(존스턴), 6px.
  - T2 카드: 상단 바. 질문 카드만 빨간 바.
  - T3 기록 프레임: 흰 4px 테두리, 좌상단 날짜, 좌하단 사진번호(불투명도 60%).
  - T4 어뢰 카운터: 우상단(높이 8–14%, 우측 여백 14%). 어뢰 PNG + 숫자.
  - T5 평면도: 관계 도식이며 방위·축척은 없다. 짙은 남색 바다. 일본 함대는 우상단, 항모는 좌하단.
  - T6 구마노 측면도: 단색 선화.
  - T7 시각 칩: 좌상단 소형.
